# SyntaxWear - Sneakers Online 👟

Bem-vindo ao repositório da **SyntaxWear**, uma plataforma de e-commerce moderna e elegante especializada em sneakers e tênis exclusivos. Este projeto foi desenvolvido com foco em uma experiência de usuário fluida, design responsivo e uma estética urbana contemporânea.

---

## 🚀 Tecnologias Utilizadas

O projeto utiliza tecnologias web fundamentais para garantir performance e compatibilidade:

- **HTML5**: Estruturação semântica do conteúdo.
- **CSS3**: Estilização avançada utilizando variáveis, Flexbox e Grid Layout para um design responsivo.
- **Arquitetura CSS Modular**: Organização de estilos dividida em base, componentes e variáveis para facilitar a manutenção.

---

## 🎨 Funcionalidades e Seções

O site conta com as seguintes seções principais:

1.  **Header Dinâmico**: Navegação intuitiva com categorias (Masculino, Feminino, Outlet) e acesso rápido à conta, suporte e carrinho.
2.  **Destaque (Hero Section)**: Banner principal apresentando o modelo "Krypton One" com chamadas para ação (CTAs).
3.  **Categorias de Estilo**: Navegação visual por estilos: Casual, Esporte, Moderno e Futurista.
4.  **Grade de Produtos**: Exibição organizada dos modelos disponíveis com foco em imagens de alta qualidade.
5.  **Rodapé Completo**: Inclui inscrição em newsletter, links para redes sociais e mapa do site.
